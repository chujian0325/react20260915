# 二、JSX
## 2.1 JSX基础-概念和本质

**什么是JSX**
概念：JSX是JavaScript和XML（HTML）的缩写，表示在JS代码中编写HTML模板结构，它是React中编写UI模板的方式
优势：
1. HTML声明式模板写法 
2. JS的可编程能力

**JSX的本质**
JSX并不是标准的JS语法，它是JS的语法糖，最终会被编译成JS代码，在浏览器中无法直接运行，需要通过解析工具(babel)解析之后才能在浏览器中运行
